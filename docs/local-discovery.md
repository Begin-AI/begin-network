# Owner-local encrypted discovery experiment

The requester encrypts a minimal matching vector/contract to an explicitly chosen participant. Forwarding/mailbox operators carry the box and signed authorization; they do not receive the plaintext vector. An opted-in owner verifies the request and its authority-selected grant, decrypts only the permitted query, checks compatible method/model/dimension and complementary roles/shared timing, and returns a proposal or no-match. The separately sealed full intention is never opened by this path.

This implements one candidate from `private-discovery-experiment.md`, anchored in the patent's local-agent execution and coordinator forwarding. It is not global private candidate discovery: the synthetic recipient is known in advance. It is not privacy against the potential counterpart, who learns the explicitly disclosed query. There is no mandatory Begin node or signing authority.

Pre-match disclosure is a distinct `match` action with purpose `begin-discovery`. It does not pretend matching has already happened. Requests bind the encrypted box digest. Input vectors are L2 normalized, finite, dimension-bounded (384 max), and compared only under identical method/model/purpose. Timing and role constraints are checked before cosine similarity. This module has no trained encoder, no human identity proof, no group membership directory, no cryptographic query limit and no safe arbitrary-code execution.

`receive_query` verifies signed input, scope and expiry, and records replay admission before decryption/computation after envelope/scope/digest checks. An admitted request that later fails cannot be automatically retried; durable outcome/recovery semantics remain unfinished. The caller supplies an opted-in owner and current local authority policy. The current direct-grant handler lacks distributed revocation freshness; `PermissionLedger` is separate pending integration. A result is a local computed outcome, not a signed receipt or transferable proof of honest computation.

Tests demonstrate owner-local authorized query access, a wrong-key forwarding operator failing decryption, no full-description disclosure, role/time/relevance rejection, expired/incorrect permission, ciphertext substitution rejection, and encrypted offline mailbox delivery with recipient scope and idempotent claim. Logs/body-size/timing/pseudonymous-recipient metadata remain visible to nodes. Endpoint compromise, collusion with owner, and adaptive inference are outside this experiment's protection. Full P2 is not passed.
